# Tritium-Tech-Solutions

## Project Overview

Tritium Tech Solutions website is a modern, responsive, animated website built with Next.js, TypeScript and Tailwind CSS. It serves as the digital home of Tritium Tech Solutions, a software house offering web development, mobile app development, AI and automation, cloud and DevOps, UI/UX design and software consulting. The site presents the company's services, working process, portfolio and values, and lets visitors send project enquiries that arrive directly in the company's inbox.

## Tech Stack

- **Next.js** (App Router), **React** and **TypeScript**
- **Tailwind CSS v4** for styling and the light and dark theme
- **GSAP** with ScrollTrigger for scroll-driven animations
- **Framer Motion** for page transitions and interface animations
- **Lenis** for smooth scrolling
- **Nodemailer** with Gmail for the contact form

## Features

- **Fully Responsive Design**: Optimized for desktop, tablet and mobile, with a mobile menu
- **Light and Dark Theme**: A navbar toggle that follows the visitor's system setting and remembers their choice
- **Modern Animated UI**: GSAP hero intro, a process timeline that follows the scroll, count-up stats, a technology ticker and smooth page transitions
- **Services Section**: Highlights Web Development, Mobile Apps, AI and Automation, Cloud and DevOps, UI/UX Design and Software Consulting, plus engagement models and an FAQ
- **Portfolio**: A project grid with category filters and project screenshots
- **About Section**: The story behind the name "Tritium", the company values and the technology toolkit
- **Contact Form**: Validates the entry, blocks bots with a hidden honeypot field and emails each enquiry to the company, so replying answers the visitor directly
- **SEO Optimized**: Page titles and descriptions, Open Graph tags, sitemap, robots file and a custom 404 page
- **Accessible Motion**: Animations respect the visitor's reduced-motion setting

## Conclusion

Tritium Tech Solutions website is a clean, professional and fully responsive software house website built with modern web technologies. It represents the company's services with performance, smooth motion and user experience in mind, and it works as both the company's portfolio and a demonstration of modern full-stack frontend development with Next.js, TypeScript and Tailwind CSS.
